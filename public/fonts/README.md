# Metropolis font files (optional)

The app loads **Metropolis** from CDN in development. For production (offline / licensing), add WOFF2 files here and switch `app/globals.css` to `@font-face` local sources.

Suggested files:
- `Metropolis-Regular.woff2` (400)
- `Metropolis-Medium.woff2` (500)
- `Metropolis-SemiBold.woff2` (600)

Download from your Figma export or your font license provider.
